No copyrighted Bible translation is bundled with this repository. The application supports
user-imported JSON translations. Users are responsible for ensuring they have permission to
store and use the text they import.

## NVI Online / YouVersion Platform

Pulpit can access the Nova Versão Internacional (NVI) online through the YouVersion Platform.
The NVI text is not part of this repository and is not licensed under GPLv3. Inline access requires
a valid YouVersion App Key and whatever license/permissions the YouVersion Platform requires for
that Bible version. The application displays the copyright attribution returned by the API and
does not persist or offline-cache the NVI response.
