# Release checklist

- [ ] `npm test` passes.
- [ ] `npm run check` passes.
- [ ] No temporary bootstrap artifacts are present.
- [ ] Backup import/export behavior remains compatible.
- [ ] Service worker cache name is bumped when the application shell changes materially.
- [ ] No copyrighted Bible translation is bundled without a documented compatible license.
- [ ] Security/privacy implications are documented for new external integrations.
- [ ] GitHub Pages workflow contains every runtime asset required by the static app.
